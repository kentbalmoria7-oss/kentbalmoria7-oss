## 👨‍💻 Professional Overview

> *"Detect early. Investigate thoroughly. Document everything."*

- 🔭 **Technical Domain:** Cybersecurity operations with a focus on Security Operations Center (SOC) workflows, alert triage, and email threat analysis.
- 🎯 **Core Strengths:** Phishing investigation, email header and Return-Path analysis, IoC extraction, and reputation checks with VirusTotal, URLhaus, WHOIS, and Hybrid Analysis.
- 🧪 **Hands-On Lab Focus:** Completing the LetsDefend SOC Analyst Learning Path and writing step-by-step investigation walkthroughs with evidence, findings, and verdicts.
- 🛠️ **Methodology:** Detonating suspicious links and files only inside isolated sandboxes, then synthesizing artifacts into clear true-positive or false-positive verdicts.
- 📚 **Continuous Learning:** Deepening skills in SIEM log analysis, network traffic inspection, endpoint investigation, and the MITRE ATT&CK framework.
- 🚀 **Career Direction:** Entry-level SOC Analyst (Tier 1), growing toward Incident Response and Threat Hunting.
